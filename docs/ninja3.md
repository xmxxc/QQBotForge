# 忍者必须死3（#72 手动授权与群内文字查询）

规格 #71 的 01 票。完整安装 `plugins/ninja3/`，并启用“群状态”“黑白名单授权”两个模块；不需要“自助问答”或旧“账户共享”。数据在插件目录 `data/ninja3.db`，与旧插件 `account-sharing.db` 互不读取、不迁移、不删除，两个插件可同时加载。

## 一条可演示流程

1. 主人登录后台打开“忍者必须死3”，选择 Bot，添加群原生 ID 并勾选“开放本群”；新增账号，填写名称、登录账号、密码，勾选“启用”并在“开放群”填入该群。新群、新账号默认都不开放。
2. 主人在该群发送 `@Bot 授权 @成员`。插件只使用平台 `mentions` 中被 @ 成员的原生 OpenID 和事件所在群；手写名称、同时 @ 多人、只 @ Bot 或非主人发送都不授权。
3. 成员在该群发送 `账号列表` 看到名称，再发送 `账号 名称`，Bot 在群内公开回复名称、账号、密码，说明和地址为空时省略。

## 规则

- 授权：成员当前在群事实不可用时，主人这条群内命令作为依据调用群状态既有人工确认（来源 `owner_confirmed`，依据含消息 ID），再在授权模块写入消费方 `ninja3`、功能 `query` 的持续来源：资源范围 `all`、长期有效。同一 Bot、群、成员、入群周期已有同样来源时不重复新增。群状态恢复未就绪（`recovery_required`、`recovery_processing`、写入中）时只回复“授权待处理”，不确认、不授权。
- 范围：一次授权覆盖本 Bot、本群、本消费方当前及以后开放的全部账号；不跨 Bot、群或消费方，不影响旧 `account_sharing` 消费方。账号的 `open_groups` 是 QQ 群原生 ID，由本插件维护；授权模块资源的分类 `groups` 始终为空，避免分类授权被群 ID 扩权。开放群列表同步到 `query` 功能的群范围，私聊关闭；该群范围由本插件维护，在“授权管理”手工改动会在下次查询时被插件按开放群覆盖。
- 查询条件：群已开放、账号已启用且在该群开放、调用者本人当前有明确授权（拒绝、框架黑名单、到期、离群、事实待核验或恢复中均不通过）。无完整名册、无私聊绑定也可以群内回复；群回复公开可见，个人授权只控制谁能触发，不代表旁观者有资格，也不生成全员资格报告。
- 发送前：全部异步读取完成后，同步复查插件数据版本（任何账号或群写入都会使在途查询失效）、插件与授权模块实例、调用及查看决定（来源、拒绝、资源启停、群范围、群事实凭据和模块代际），通过后立即发送；否则回复“账号或授权刚刚变化，请重新发送查询”。后续的暂停／紧急状态应加入同一检查。
- 未授权：`账号列表` 和 `账号 名称` 在读取账号记录前就判定资格，被拒时不读取账密。同一 Bot、群、成员首次立即私聊主人，十分钟内后续尝试只累加次数；本次确实送达主人时回复“你暂无查询权限，已通知主人”，合并或未送达时回复“你暂无查询权限，已记录给主人”。拒绝名单和框架黑名单不通知；未开放的群只回复“本群未开放账号查询”，不通知；群状态处理中提示稍后重试，不通知。主人须先私聊 Bot 发送 `忍3` 登记通知地址；未登记、平台拒绝或结果未知时通知保留在后台“未授权查询通知”，可重试，重试不授权也不发账密。
- 管理：后台接口 `GET/POST/PATCH/DELETE /api/ext/ninja3/accounts[/ID]`、`GET/POST /api/ext/ninja3/groups`、`DELETE /api/ext/ninja3/groups/<群ID>`、`GET/POST /api/ext/ninja3/notices`，均需框架后台会话，返回 no-store。接口不返回密码；同 Bot 账号名称不可重复，开放群须先添加。删除群同时从所有账号移除。撤权、拒绝、到期调整使用“授权管理”的 `ninja3` 消费方。
- 日志：新操作日志只记录 Bot、群、成员、账号 ID 与结果，不含密码。框架消息正文日志是否记录回复正文沿用现有约定，本插件不改变。

## 验证

`tests/bot_modules/test_ninja3.py` 使用真实 PluginManager 同时加载旧账户插件与本插件、ModuleManager 加载群状态和授权、WSClient 原始生命周期事件、鉴权 HTTP 和临时 SQLite，只替换 QQ 发送端。覆盖两个 Bot 与两个群、@ 原生身份、非主人与伪造显示名、无名册群内回复、恢复屏障、拒绝优先、通知十分钟合并与后台待办、停用／关闭／移出范围／删除／离群，以及查询准备期间改密、停用、关群、撤权、拒绝、离群、授权模块重载和插件重载均不发旧内容。未连接真实 QQ；页面只做脚本语法检查。
