# 主人菜单

在群内或真实私聊发送 `主人菜单` / `主人命令`。忍3菜单给主人显示【主人菜单】；私聊先选择已知群。每次点击都重新检查当前主人与框架黑名单；菜单和确认按钮五分钟有效，重载后失效，按钮绑定发起主人、Bot 和原消息场景。私聊中选择的业务群保存在服务端，保持真实私聊事件。

群状态显示待恢复原因，提供刷新、Bot 级恢复基线和【全部确认在群并恢复】。批量确认只处理本次读取的已记录成员（包含历史离群记录），依据记录“主人在主人菜单批量确认”，不补齐完整名册、不授角色或功能资格。恢复基线本身影响此 Bot 的所有已知群；只有返回成功且最新状态 ready、无 pause 才显示完成，变化或部分失败显示确认数量和原因。

授权分区包含成员、授权、拉黑和未授权查询通知列表。每页四人，最后一行翻页和返回；名字复用显示名接口。群内打开名单时主动私聊发起主人，只有明确送达才回复“已私聊发送”；没有已观察私聊地址、拒绝或结果未知时仅回复数量和私聊重开提示。全局拒绝会显示，但【解除】只解除本群的来源。拉黑复用 #143 的一次确认及条件写入保护；状态改变需重新操作。

忍3分区列出账号与脱敏登录名，提供单个或全部账号的批量改密、进度、取消未开始项和本群开关。使用现有改密批次/任务；全部账号选择后用五分钟确认按钮，单个账号选择后直接确认执行。取消不撤回已完成的远端改密；无密钥、账号变化等拒绝沿用现有引擎。

更新器已初始化时提供更新分区：检查、更新到最新、查看进度。沿用原有 CI、版本祖先、锁、备份与重启保护，任务结果在原消息场景回复。实际更新可能触发既有更新器的重启流程。

连接 READY / RESUMED 或群状态依赖可用后，若有已知群待恢复且 Sender 可用，给主人推送一次卡片；使用已有观察到的真实私聊地址。卡片按钮重新读取所有已知群并确认已记录成员，再做一次 Bot 级恢复。拒绝只记录返回码，不循环重发；下次打开菜单仍突出待恢复。没有地址可先私聊打开菜单供以后启动使用。

假平台测试证明事件解析、请求、按钮与拒绝分支，不证明真实主动消息送达。现场需记录部署 SHA、实际恢复结果、平台是否允许主动私聊、卡片和按钮能否使用；平台拒绝按实际结果登记。本票开发不执行真实 QQ、改密、更新、重启或部署。
