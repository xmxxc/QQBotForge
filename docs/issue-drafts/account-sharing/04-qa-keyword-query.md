# 04：复用自助问答模块完成关键词账户查询

GitHub 实施票：[#6](https://github.com/xmxxc/QQBotForge/issues/6)，父规格 [#2](https://github.com/xmxxc/QQBotForge/issues/2)。

## Parent

[账户共享管理需求规格](../../specs/account-sharing.md)。覆盖 R18—R21。

## What to build

主人管理精确、包含和多关键词规则，成员发送关键词即可进入同一账户查询流程。自助问答作为独立模块同时支持普通静态回复匹配，返回规则结果供消费插件处理。

## Acceptance criteria

- [ ] 通过 Web 和主人命令新增、编辑、启停规则，默认精确匹配；多关键词可引用同一回复或账户。
- [ ] 精确优先；包含按显式优先级、未设置时按较长关键词确定；仍并列时给有权候选选择。
- [ ] 相同账户重复命中只出现一次，无权候选不展示；未命中普通聊天不回应。
- [ ] 模块按 Bot 和消费方命名空间隔离规则，匹配结果提供稳定规则/目标引用；不把账户密码存成规则执行逻辑。
- [ ] 账户插件对匹配结果再次鉴权并读取当前账户，停用、删除、撤权后不能通过旧关键词取值。
- [ ] 模块提供静态回复及通用匹配能力，消费方明确准入策略；不会自行监听并回复所有群。
- [ ] 用第二个最小消费方验证可复用性，无需复制账户逻辑；首版不执行外部动作。

## Verification

从管理操作到群/私聊查询结果验证规则冲突、多个别名、同账户去重、无权候选过滤、即时编辑及不同 Bot/消费方隔离。模块的公开匹配接口补少量确定性排序测试。
