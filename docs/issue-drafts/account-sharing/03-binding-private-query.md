## Parent

[账户共享管理需求规格](../../specs/account-sharing.md)。覆盖 R12—R14、R22 的公共查询入口、R23 的私发路径、R28、R30 的单次操作结果。

## What to build

主人授权后才启动身份关联流程。成员完成经过验证的群身份与私聊身份绑定，即可在私聊选择授权群并查询账户；在群里发起查询时先提示，再尝试向绑定的私聊身份发送账密。此切片保持实际私发，后续单独开放满足全员条件的群发。

## Acceptance criteria

- [ ] 授权保存、绑定、通知、发送账密分别记状态；授权操作不会自动发送密码，通知失败不回滚已经保存的授权。
- [ ] 已有可靠绑定可复用；无映射时进入待绑定并引导；证据不足由主人确认，不凭字符串相同或输入 QQ 号自动绑定。
- [ ] 绑定验证调用者对两侧身份的关联，不接受可被他人抢用的公开凭据单向完成映射；所有映射限当前 Bot，保留群原生及私聊标识。
- [ ] 支持主人私聊、群聊和 Web 发起授权后的流程；无法私聊联系时只给绑定引导，不假报成功。
- [ ] 私聊只有一个有效授权群时自动选择，多个时选择有权群，没有有效群时拒绝；选择后重新计算资源权限。
- [ ] 私聊查询私发；群内查询先给将尝试私发的提示，账密只发送给经过绑定的查询者，不能用群成员 ID 直接调用私聊 API。
- [ ] 无好友关系、拒收、接口失败等分别反馈；私发失败不公开密码、不撤销授权、不显示已送达。
- [ ] 文字、后续按钮和关键词共用查询业务入口，读取及发送前都能重新检查当前授权。
- [ ] 主人能在后台查看单次授权/绑定/发送结果，并可继续处理待绑定申请；普通成员不能查看他人的申请。
