# 07：按功能范围拉黑、设置到期并解释权限

GitHub 实施票：[#9](https://github.com/xmxxc/QQBotForge/issues/9)，父规格 [#2](https://github.com/xmxxc/QQBotForge/issues/2)。

## Parent

[账户共享管理需求规格](../../specs/account-sharing.md)。覆盖 R08—R10，并验证所有授权来源的拒绝优先。

## What to build

主人可以对群或成员设置适用于单功能、功能授权组或全部功能的黑名单，给个人和批量授权设置期限，并从 Web/命令查看某成员对某账户为什么可用或不可用。

## Acceptance criteria

- [ ] 群/成员的适用拒绝覆盖直接、批量、功能授权组、全部功能及持续资源授权；重新授予不能覆盖拉黑。
- [ ] 范围拉黑只影响适用功能；解除一条拒绝后仍有其他适用拒绝则继续拒绝。
- [ ] 默认长期有效，可单独或批量设置到期时间；读取时实时判断到期，不等后台清理。
- [ ] 主人可查看允许/拒绝原因、授权来源、期限及成员状态，不向普通查询者暴露其他成员信息。
- [ ] 解释区分无调用资格、无资源资格、适用拒绝、到期和待核验；只有需要私聊映射的操作才检查绑定条件。
- [ ] 修改拒绝、期限或撤销后，目录、关键词及已存在的查询会话通过同一决策立即生效。
- [ ] 在状态切换及读取期间发生到期也不能沿用旧决定发送；发送前重新判断当前决策版本和时间。
- [ ] 通过 Web 和主人命令操作同一规则，并对批量部分失败给真实结果。

## Verification

用可控时间从公开管理入口配置规则，再从查询入口验证多来源授权、跨范围黑名单、边界到期和解除后仍被其他规则拒绝。规则改变后检查已有会话，按钮适配存在时也走同一查询决策。
