# 06：按账户分组和功能授权组批量授权

GitHub 实施票：[#8](https://github.com/xmxxc/QQBotForge/issues/8)，父规格 [#2](https://github.com/xmxxc/QQBotForge/issues/2)。

## Parent

[账户共享管理需求规格](../../specs/account-sharing.md)。覆盖 R02 的账户分组、R06、R07、R10 的来源解释。

## What to build

主人通过 Web 和命令选择单功能、功能授权组或全部功能，再选择单账户、账户分组或全部账户，对指定成员批量授权。明确选择一次批量或持续授权，后续新增资源按选择生效。

## Acceptance criteria

- [ ] 默认独立功能授权，功能授权组由主人显式指定；账户分组与功能授权组有不同名称和选择控件。
- [ ] 同一成员的授权仍限 Bot＋群，不因全部功能授权扩散到其他群/Bot或消除成员资格要求。
- [ ] 资源支持单个、分组、全部；一次批量保存当前目标，持续授权在当前及未来符合范围的资源上生效。
- [ ] 界面和命令明确是否包含未来功能/资源；全部功能的当前批量与持续范围也不能静默混淆。
- [ ] 新增、移出分组、停用、删除账户后，目录及直接查询立即按当前范围和明确的授权类型判断。
- [ ] 授权解释显示直接/功能组/资源组/全部的来源，撤销一个来源不误删其他仍有效来源；明确拒绝仍优先。
- [ ] 支持多成员批量授予和撤销，显示逐项结果及部分失败；失败项不会伪装成全部成功。
- [ ] 第二个消费功能可以选择共享或独立的功能范围，证明模块没有硬编码账户共享。

## Verification

管理操作后从成员目录和查询入口验证一次/持续、新增未来资源、分组迁移、多来源撤销、跨 Bot 隔离及批量部分失败。
