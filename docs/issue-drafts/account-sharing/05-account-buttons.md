# 05：点击账户按钮直接查询并支持分页

GitHub 实施票：[#7](https://github.com/xmxxc/QQBotForge/issues/7)，父规格 [#2](https://github.com/xmxxc/QQBotForge/issues/2)。

## Parent

[账户共享管理需求规格](../../specs/account-sharing.md)。覆盖 R14 的群选择按钮、R21、R22、R28 的按钮私发、R29。

## What to build

成员点击“账户列表”后，每个有权账户就是一个可点击按钮，点击账户名称直接查询；账户多时分页。按钮不可用时提供等价文字操作。

## Acceptance criteria

- [ ] 通用入口、群选择、个人账户列表、翻页均接入已有查询流程；每个账户按钮直接查询。
- [ ] 每次点击按实际点击者、Bot、群上下文及当前资源重新鉴权；他人不能借用个人菜单的身份，旧按钮不能越过撤权、到期、停用或删除。
- [ ] 回调入口显式执行权限判断，不能依赖普通消息拦截器、owner_only、客户端按钮权限或 ACK 作为业务授权。
- [ ] 按钮只携带查询引用，不内嵌密码；读最新账户信息；损坏、过期或不匹配的上下文给可恢复提示。
- [ ] 独立完成交互 ACK 和实际发送；群点击不能默认用普通群回复发密码，私发仍走可靠私聊映射。
- [ ] 根据平台实际能力构建受支持的消息及按钮；按钮权限不足或客户端不支持时降级到文字列表/查询，不能伪造按钮发送成功。
- [ ] 未授权点击限频提示，未命中业务按钮不误消费其他插件回调。
- [ ] 分页不会让后续页面或跨页缓存绕过当前资源权限。

## Verification

用真实交互事件入口验证按钮到最终发送，覆盖他人点击、伪造/过期引用、跨 Bot、跨群、分页中撤权、平台按钮拒绝及私发失败。不向真实群发测试密码。
