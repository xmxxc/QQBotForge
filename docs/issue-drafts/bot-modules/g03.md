# 群状态：接入生命周期和断线恢复并发布可信变化

Issue：https://github.com/xmxxc/QQBotForge/issues/23

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

成员或 Bot 进出群、断线和重启后，群状态先更新可信性，再通知消费方；可靠核验与恢复确认完成后才报告可用。

## Acceptance criteria

- [ ] 通过已验收公开接口接收四类群生命周期；保留原生身份和可用顺序，不重复应用同一事件。
- [ ] 角色有实际事件时消费事件，没有时可靠核验并报告覆盖限制；不假造平台通知。
- [ ] 重复、迟到、同秒冲突及缺少标识／时间／身份采用保守状态；已知事实变化先失效快照和消费凭据，再完成历史持久化。
- [ ] 首次启动、重启、未知连续性、Bot 被移出和事件处理失败暂停相关事实；恢复需可靠重建基线或可信补发及本地处理完成。
- [ ] 消费通知有完成、失败、超时、取消、卸载和版本语义；旧回调或重载不得恢复过期信任；不依赖账户插件是否启用。
- [ ] 真实框架原始事件到群状态再到测试消费者，验证顺序屏障、断线恢复、持久化延迟和多 Bot／群影响范围；发布接口说明。

## Existing implementation

授权当前仅有模拟观察源；框架新接口已存在，需经精确版本验收后适配。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
