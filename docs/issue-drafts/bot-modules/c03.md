# 账户共享：严格全员群发、逐人诊断及恢复设置

Issue：https://github.com/xmxxc/QQBotForge/issues/35

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

主人按群和账户启用群发，失败看到逐人原因；资格失效后转私发，按主人选择决定是否恢复群发。

## Acceptance criteria

- [ ] 群发须主人显式启用该群／账户，并通过含本 Bot 和其他 Bot 全员调用及查看权；每次派发前复查。
- [ ] 通过授权统一全员报告，账户插件不直接查询平台名册或解释通用内部状态；不提供强制绕过。
- [ ] 新人、撤权、拒绝、到期、角色／成员变化、名册不完整或断线使旧群发资格失效，各账户分别判断。
- [ ] 主人私有报告区分明确不合格、待核验和不完整，提供已确认身份和原因；群内仅给状态，随后尝试私发。
- [ ] 目标／实际模式分开，自动恢复按群／账户默认关闭；手动恢复或开启自动恢复都要重新核验，主动关闭清除恢复意向。
- [ ] 模式恢复不主动发密码；测试人工／自动恢复、Bot 不合格、并发状态变化与失败／未知发送结果，记录能力核查边界。

## Existing implementation

现有群发、模式和诊断有模拟验证；全员事实证明下沉后需接通实际事件验收。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
