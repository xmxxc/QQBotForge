## What to build

主人配置图文、Markdown 和按钮组合，用户能选择答案、翻页、发查询指令或打开链接，平台不支持时得到可用降级。

## Acceptance criteria

- [ ] 后台／命令可配置文字、图片、Markdown 及按钮组合，界面说明实际 Bot 能力和不支持项。
- [ ] 复用框架已有发送与按钮能力，支持答案选择、翻页、查询指令和打开链接；按钮引用规则／会话而不含敏感答案。
- [ ] 交互绑定真实主体并在点击时调用当前准入检查；任何格式或降级路径不能绕过规则权限。
- [ ] 平台拒绝按钮／Markdown／媒体时按可确认结果降级为文字、链接或明确失败；发送结果未知时不盲目重复派发敏感内容。
- [ ] 公开群回复和私聊回复目标正确；删除／修改规则后旧按钮不返回旧内容。
- [ ] 用平台能力替身验证各格式、组合、拒绝和回调；真实 Bot 许可与浏览器核查未做时单独标记。

## Existing implementation

框架具备多种发送与按钮基础，先对照上游关键词回复复用合适能力。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
