# 群状态：独立查看和刷新已知群及 Bot 状态

Issue：https://github.com/xmxxc/QQBotForge/issues/21

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

主人独立启用群状态模块，通过后台和命令查看当前 Bot 的已知群、Bot 在群状态及来源信息，并主动刷新。

## Acceptance criteria

- [ ] 群状态模块独立发现、启停和重载；不安装授权、问答或账户扩展也能使用。
- [ ] 后台及主人命令展示已知群、原生标识、来源、时间、Bot 在群状态和平台能力，接口和页面使用同一事实。
- [ ] 接口未提供全量群列表时标明已知范围；刷新失败保留历史与错误，不伪称当前或全部群。
- [ ] 按 AppID 分区；未登录后台及普通成员不能枚举名册或修改状态；写入沿用现有鉴权与同源保护。
- [ ] 提供稳定的只读快照、刷新结果及能力信息接口，消费者不读取内部数据库。
- [ ] 使用真实模块加载、HTTP／QQ 主人入口和临时数据库验证，交付独立使用说明。

## Existing implementation

现有授权内含部分 Bot／群事实，尚无独立群状态模块。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
