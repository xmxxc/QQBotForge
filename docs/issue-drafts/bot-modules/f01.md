# 框架：核对并验收群事件、连接及本地恢复公开契约

Issue：https://github.com/xmxxc/QQBotForge/issues/20

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`main`；框架 PR 目标为 `main`。

## What to build

群状态消费者通过公开接口取得原生成员变化、连接事实和已处理恢复凭据；交付可复现的真实接线示例及精确版本矩阵。

## Acceptance criteria

- [ ] 先核对已经合入的群生命周期／连接状态接口和本地已有恢复实现，记录上游、main、personal 的精确版本及剩余差异。
- [ ] 真实事件入口保留原生 Bot／群／成员、事件标识、时间和顺序信息；已知同群变更在相关业务调度前完成通知结果登记。
- [ ] 验证普通插件停用、维护、黑白名单不屏蔽模块观察；回调失败、超时、取消、卸载、重载与迟到写入明确影响可信性。
- [ ] 验证首次启动、新会话、断线补发、固定边界内本地处理及确认；READY／RESUMED 和后台任务启动不能单独作为恢复依据。
- [ ] 能力查询区分官方 WS、Webhook 及不受支持来源；检查依赖消费者、重建基线、事件缺口、持久化延迟和顺序交错。
- [ ] 对精确实现版本运行实际框架接线测试并发布契约和示例；框架修复单独提交到 main，再同步给 personal，业务尚未验收继续明确标记。

## Existing implementation

上游群生命周期与连接状态 PR 已合入；personal 已有本地恢复接口与后续修复。原 #16 的待交付描述已落后于实际代码，不能据此重写已存在能力。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
