# 基础：解除存储安装耦合并验证现有数据兼容

Issue：https://github.com/xmxxc/QQBotForge/issues/19

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

分别安装问答、授权以及现有账户扩展时，能使用各自存储；普通问答不再需要授权目录，现有账户和授权数据保持可管理。

## Acceptance criteria

- [ ] 对照插件市场及关键词回复、群管源码，记录固定提交、候选行为、可复用接口、版本兼容和许可条件；先查现成能力再实现。
- [ ] 问答单目录在真实模块管理器中加载，持久化规则并完成公开静态回复；不安装、不启用授权均可工作。
- [ ] 使用现有上下文数据路径与标准 SQLite；通用存储复用不引入必装的授权业务依赖或第四个业务模块。
- [ ] 用旧格式临时数据验证账户稳定 ID、规则、来源、期限、拒绝、成员周期、绑定和待办读取；迁移可重跑，部分失败不丢数据或复活资格。
- [ ] 以真实加载与管理入口验证迁移前后主人 CRUD／预览和旧敏感查询拒绝行为，运行实例数据保持原样。
- [ ] 交付独立安装示例、迁移说明和自动验证；必要时采用先兼容、再迁移、最后移除旧依赖的顺序。

## Existing implementation

已有通用 SQLite 存储及三扩展；目前问答和账户从授权包导入存储，已有独立安装测试同时复制三扩展。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。

## Blocked by

无，可立即开始。

## Verification

使用真实模块加载、管理／消息／框架事件入口，临时数据库、假身份及平台替身验证可演示行为；不读取运行凭据或连接真实 QQ。分别报告算法、实际接线、浏览器和真实平台许可证据。
