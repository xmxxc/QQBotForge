# 授权：完成范围批量、期限、拒绝和权限解释

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

主人能精细或批量配置功能、资源范围和期限，并通过统一解释看清每个主体为何可用或不可用。

## Acceptance criteria

- [ ] 保留单功能、功能授权组、全部功能以及单资源、资源组、全部资源的显式选择；任何全部不跨 Bot。
- [ ] 一次快照和持续授权各有来源，新增／移出资源按范围重算；源级撤销、批量逐项成功／失败和部分重试可核查。
- [ ] 框架拒绝和适用明确拒绝优先于角色与正向授权；重新授权不解除拒绝；到期立即失效，旧按钮不能延长权限。
- [ ] 返回资格、原因、适用来源、成员状态、版本及有效期；支持发送前检查，私有策略变更收窄无关影响而共享成员变化仍全体相关失效。
- [ ] 主人页面与命令编辑同一策略，普通人不可读他人详情；群角色不会自动获得账户管理或查看权。
- [ ] 从真实管理入口验证多来源、分组变更、到期边界、持续资源、拒绝优先及同 Bot 多消费方独立性。

## Existing implementation
