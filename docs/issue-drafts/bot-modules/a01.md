# 授权：独立管理群成员策略并实现消费方隔离

Issue：https://github.com/xmxxc/QQBotForge/issues/24

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

主人不用账户插件即可管理一个消费方的准入、明确授权和角色策略，并查看资格原因；授权复用群状态事实。

## Acceptance criteria

- [ ] 独立后台／主人命令可配置群准入、成员和功能／资源基本授权、撤销、明确拒绝及解释。
- [ ] 消费方可明确选择公开、群／成员、角色或明确授权策略；公开不绕过适用拒绝，且不强迫执行无关的群连续性检查。
- [ ] 使用群状态提供的成员、角色、周期和可信性；退群撤销该群全部明确来源，重入需主人重新授权，其他群独立且拒绝保留。
- [ ] Bot、消费方、功能与资源归属明确，冲突标识不能静默共享；不同消费方默认不串权。
- [ ] 局部存储或业务失败不污染无关 Bot／消费方；共享事实或整体存储失效准确暂停所有实际依赖方，恢复不得复活旧资格。
- [ ] 通过真实管理和框架事件入口验证多 Bot／消费方、退群重入、状态失效和可控局部故障；公开资格、原因及有效性检查接口。

## Existing implementation

已有明确授权、拒绝和周期算法；#17 已指出全局健康标记及标识隔离问题，需在新职责内解决。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
