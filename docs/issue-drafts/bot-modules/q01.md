# 问答：独立配置并使用公开文字问答

Issue：https://github.com/xmxxc/QQBotForge/issues/28

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

只安装问答模块，主人就能通过页面／命令配置公开规则，成员在启用范围内发送文字并获得回复。

## Acceptance criteria

- [ ] 独立发现、启停和重载；群状态、授权、账户目录均不存在时仍可持久化和回复公开问答。
- [ ] 主人后台／命令配置 Bot、群及私聊启用范围，全局／分群规则，增删改、规则及关键词启停、多个关键词和精确／包含匹配。
- [ ] 接入真实 QQ 消息入口，沿用框架 @ 与消息过滤策略；未命中不回应，重复加载不重复注册或回复。
- [ ] 公开指在主人启用范围内无需个人正向授权；框架拒绝始终生效，默认不会向所有未知群自动开放。
- [ ] 保留消费方命名空间和可供插件调用的匹配接口；普通问答入口与账户消费规则不重复处理。
- [ ] 以真实模块管理器、鉴权 HTTP／命令和群／私聊消息验证到最终文字回复；交付独立安装使用说明。

## Existing implementation

已有匹配和静态 answer 接口；配置与消息入口目前依附账户插件，尚不具备独立问答产品。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
