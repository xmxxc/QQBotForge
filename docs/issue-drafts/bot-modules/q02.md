# 问答：正则、统一排序和多答案选择

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

## What to build

主人配置精确、包含或正则；用户命中多个答案时按统一规则得到最佳答案或可点击选择列表。

## Acceptance criteria

- [ ] 保存时验证正则并提供测试反馈；非法规则不破坏既有有效配置，执行资源受限且不阻塞其他 Bot。
- [ ] 精确优先于包含，包含优先于正则；同类可设置优先级，包含未设置时较长关键词优先。
- [ ] 全局与本群共同参与，不自动遮盖；按当前准入过滤后排序和去重，最佳并列时只展示有权标题。
- [ ] 提供候选选择与分页，菜单绑定实际 Bot／调用者／上下文；点击重新读取当前规则，删除／停用／改权后旧菜单失效。
- [ ] 优先按钮，平台拒绝时有等价文字选择；ACK 与发送分开，回调不能借用原点击者资格。
- [ ] 使用消息到结果测试精确／包含／正则、并列、别名去重、旧菜单、跨用户点击及正则异常。

## Existing implementation

已有精确／包含、优先级和账户按钮基础；正则与普通问答候选流程需要补齐。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
