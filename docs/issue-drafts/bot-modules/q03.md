# 问答：逐规则权限与按群委托管理

Issue：https://github.com/xmxxc/QQBotForge/issues/30

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

主人给不同规则设置公开或受限策略，并可委托当前群主／管理员维护本群问答。

## Acceptance criteria

- [ ] 规则继承默认策略或单独设置群、成员、角色及资源限制，全部通过授权模块；不维护第二套名单。
- [ ] 先检查当前资格再显示候选和内容；适用明确拒绝优先，公开策略不解除拒绝或扩展启用范围。
- [ ] 默认仅主人管理；主人按群开放委托后，当前群主／管理员只能通过群命令管理本群规则。
- [ ] 委托者不能改全局、其他群、授权策略、自己的委托或账户配置，也不能取得后台登录权限。
- [ ] 委托撤销、角色改变、未知角色或依赖不可用使旧管理请求失效；受限回复／委托暂停时无关公开问答仍可用。
- [ ] 真实消息及管理入口测试越权、全局／分群并列、角色变更、不同群／Bot 和依赖卸载，页面明确显示受限能力状态。

## Existing implementation

账户命名空间已有鉴权匹配编排；需要形成普通问答的独立逐规则策略与委托流程。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
