# 账户共享：统一关键词、目录、按钮与私聊查询

Issue：https://github.com/xmxxc/QQBotForge/issues/34

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

获授权成员通过目录、关键词或单账户按钮查询最新账密，所有入口使用同一权限和身份上下文。

## Acceptance criteria

- [ ] 默认仅白名单群使用且每个成员须主人明确授予调用及资源资格，群准入或群角色不代替账户授权。
- [ ] 目录、候选和每账户按钮仅显示当前有权且启用的资源，支持分页、群选择、回调 ACK 与文字降级。
- [ ] 私聊始终私发，群内未开启严格群发时状态提示后私发；缺少绑定／平台拒收反馈真实结果，不回退公开。
- [ ] 读取最新账密后在派发前复查身份、群事实、策略、规则版本及有效期；他人点击、旧授权／周期／规则不能复用。
- [ ] 未授权入口限频给简短提示，普通聊天不回应，不向普通成员透露账户名或其他人权限；失败不逐次打扰主人。
- [ ] 通过实际模块与消息／按钮入口验证两 Bot／群、关键词冲突、私聊绑定、到期、撤权、退群重入和最新密码。

## Existing implementation

现有查询和按钮算法已有模拟用例，新票负责通用接口迁移和真实接线验收。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
