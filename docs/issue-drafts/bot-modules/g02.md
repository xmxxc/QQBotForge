# 群状态：核验分页名册、成员角色和完整性

Issue：https://github.com/xmxxc/QQBotForge/issues/22

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

主人刷新群成员列表并查看角色、Bot 身份及完整性；消费者可可靠区分完整名册、单人核验和历史记录。

## Acceptance criteria

- [ ] 复用可用平台单成员及分页读取能力，使用群原生身份，保留角色、来源、时间和平台能力边界。
- [ ] 中断、重复成员／游标、缺页、角色缺失、无许可和检查中成员变化均不能产生错误的完整证明；包含本 Bot 和其他 Bot。
- [ ] 已知成员缺失需解释冲突，不能直接当作成员已退群；空值、异常和权限不足保留未知原因。
- [ ] 单成员自动／主人有依据核验只更新该成员，不证明全群名册完整；既有历史名单与可靠新快照分开。
- [ ] 后台、命令及消费接口提供快照版本与更新结果，名单或角色变化使旧证明失效。
- [ ] 真实入口测试覆盖完整多页、各类不完整、两个 Bot／群及并发变更；文档说明保证范围。

## Existing implementation

现有授权中的成员读取和分页核验算法可迁移；需要形成独立事实接口。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
