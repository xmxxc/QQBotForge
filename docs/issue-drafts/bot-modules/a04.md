# 授权：提供全员资格报告及发送前有效性检查

Issue：https://github.com/xmxxc/QQBotForge/issues/27

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

消费者提交功能、资源和所需动作，即可取得含 Bot 的全群资格报告和最终检查结果，不再自己查询平台名册或解析授权内部状态。

## Acceptance criteria

- [ ] 只使用群状态的完整本轮名册及可信角色；覆盖本 Bot 和其他 Bot，不以历史活跃名单或人数代替。
- [ ] 按消费方请求的查看／调用动作检查每个接收者；受限问答全员查看，账户同时全员调用及查看。
- [ ] 报告区分明确无权与完整性未知，输出已确认成员、原因及可用身份，不宣称列出未知全部失败者。
- [ ] 返回可供发送前检查的事实／策略版本及有效期，已知成员、角色、授权或期限变化立即使旧报告失效。
- [ ] 同一成员检查不要求插件读取平台响应、名册内部结构或资格版本字段；管理报告仅主人可见。
- [ ] 真实事件和消费者发送入口测试覆盖检查中退群／新人／到期、Bot 不合格、分页失败和局部范围隔离。

## Existing implementation

现有账户群发逻辑直接读取授权 reader 和快照内部字段，需下沉通用证明部分。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
