## Parent

## What to build

主人能在统一入口处理授权、绑定、核验、群发和通知待办，并按说明分别体验三个模块及账户共享组合。

## Acceptance criteria

- [ ] 按 Bot／群／成员／账户筛选待办，直接处理或跳转通用模块对应管理入口，无需编辑数据库。
- [ ] 授权、绑定、核验、模式、通知和密码发送状态独立；批量汇总与逐项结果准确，重复事件／通知重试不重复报成功。
- [ ] 主人通知仅用该 Bot 已验证私聊目标，失败留存后台；群里只给状态，不自动附带账密。
- [ ] 分别演示群状态独立、授权独立消费、公开问答独立、受限问答和账户组合；验证单向依赖与多 Bot／消费方隔离。
- [ ] 从真实框架事件入口验证授权后绑定、关键词／按钮查询、新人使群发失效、退群撤权、重入重新授权及断线恢复。
- [ ] 更新安装／配置／升级／迁移／故障说明，精确记录测试版本与结果、浏览器和真实平台核查状态；各新子票满足条件再完成，部署和合并另行授权。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
