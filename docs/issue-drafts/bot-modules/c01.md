## What to build

主人继续管理原账户与分组，插件使用通用授权、身份上下文和问答匹配，旧数据保持可核对。

## Acceptance criteria

- [ ] 主人后台／QQ 命令保留账户 CRUD、启停、分组、批量、稳定 ID 和私聊预览，非主人及群委托者无管理权。
- [ ] 账户、规则、来源、期限、拒绝、绑定和待办通过临时副本迁移验证，不扩大授权或恢复已撤销来源。
- [ ] 群身份和私聊上下文复用授权模块；普通问答配置、成员事实和通用绑定管理从账户插件职责迁出。
- [ ] 账户以独立消费方和资源归属注册，关键词返回资源引用，匹配核心不保存账密或执行改密动作。
- [ ] 单个账户停用立即不可查；删除直接授权及入口清理，同名新 ID 不继承旧权限；授权成功不自动发送密码。
- [ ] 旧主人管理用例与新独立模块组合安装验证通过，说明现有日志可能记录回复正文及当前能力限制。
