# 问答：受限群回复转私发及跨群身份复用

Issue：https://github.com/xmxxc/QQBotForge/issues/32

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

群内查询受限内容时，全群均可查看才群发，否则状态提示后私发；成员私聊可使用可靠绑定和有效群上下文。

## Acceptance criteria

- [ ] 公开问答在群内直接回复；受限问答先确认提问者资格，再通过授权模块检查含 Bot 的全员查看权。
- [ ] 名册不完整或其他接收者无权时群内仅给状态，向提问者已验证私聊身份发送；提问者资格未知时先拒绝。
- [ ] 缺少绑定时给申请／主人处理引导；私发失败报告真实原因，不回退群发答案、不取消已有授权。
- [ ] 私聊群限定规则复用授权模块的绑定与单／多群选择，公开私聊无需绑定；退群、角色变化和拒绝即时影响查询。
- [ ] 文字、图片、Markdown、按钮和旧菜单均经过相同资格及发送前检查；不在候选、状态提示或按钮载荷泄漏受限内容。
- [ ] 验证两个 Bot、多个群、不同消费方、全员不合格、绑定缺失、断线、依赖卸载与发送失败的完整入口流程。

## Existing implementation

现有账户私发与全员策略可参考；普通问答应复用通用接口，不继承账户专用提示和开关。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
