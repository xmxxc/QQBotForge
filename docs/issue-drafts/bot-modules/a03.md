# 授权：通用身份绑定与私聊群上下文

Issue：https://github.com/xmxxc/QQBotForge/issues/26

## Parent

父规格 #18：https://github.com/xmxxc/QQBotForge/issues/18。

开发归属：`personal`；扩展 PR 目标为 `personal`。

## What to build

成员完成可靠身份绑定后，可在私聊选择仍有效的群资格，供问答与账户共享共同使用。

## Acceptance criteria

- [ ] 从真实私聊事件识别私聊原生身份，群成员、私聊、union 和 QQ 号分开；可靠平台证据或主人核实后确认关联。
- [ ] 绑定与授权独立，申请编号、公开群信息或相同字符串不能自动授予／证明关联；新成员不自动联系。
- [ ] 主人通过独立授权入口处理待绑定，授权完成、绑定待处理和通知结果分开；角色委托者不能确认他人身份绑定。
- [ ] 一个有效群可自动选择，多群展示有资格的候选；切换、退群、角色变化、到期和拒绝后重新检查。
- [ ] 公开私聊不需要群绑定；群限定私聊不得绕过当前群准入与资格，平台无法私发给出准确状态。
- [ ] 验证两个消费方复用同一可靠关联而不共享授权，两个 Bot 身份分区及待审／失败／重入场景；迁移旧账户绑定不扩权。

## Existing implementation

现有身份绑定在账户插件内，需要迁移为通用授权能力。

现有代码和历史测试为迁移基础，完成条件以本票验收为准。
